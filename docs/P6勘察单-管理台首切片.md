## 一、勘察结果（现状+凭证）

**1. C10 控制面：API 全齐、零消费方。**
`morgans/NewsControlSettings.kt` 五键位全备（:85-89 `news_control_triggers`/`news_control_event_overrides`/`news_control_user_fleet_override`/`news_control_director_tuning`/`news_control_proactive_gate`），读写 suspend 方法全备（:94-148：`writeTrigger`/`writeEventOverride`/`writeUserFleetKeyOverride`/`writeDirectorTuning`/`writeProactiveGate`）。**write\* 系列 main 源零调用方**（grep 全仓仅定义处命中）——管理台切片=给这套 API 接面板，无一行后端要补。默认表金样已有（NewsControlSettingsBlobsTest 4 例锁对称）。

**2. C11 发射闸：读侧就绪。**
`notification/ProactiveLaunchGate.canLaunch` 读 `proactiveGate()`（默认 enabled=false=现行为）；闸点在 `NotificationScheduler.scheduleInternal`（block→cancelCharacter+clearSnapshot）。开闸=写 `ProactiveGate(enabled=true)` 一行；人设系数 `personaCoefficient`、情报白名单 `intelWhitelist` 均为面板直写字段（现白名单空表=零 bypass）。

**3. B8 文游引擎：管道就绪、零入口。**
`director/DirectorTextGameService.advanceTurn(TurnRequest(castUuids, hostConversationUuid, mode))`（:50-62，Mode=PARTICIPANT/BACKGROUND）。生产调用方**零**（仅 AnchorInjectionBuilder 常量引用+测试 7 例）。镜像已走 SystemEventJson 信封（dcce023）。入口面需要：cast 多选＋host 会话选择＋模式二选＋推进动作＋回合渲染。

**4. B9 观测辅助。**

**导演控制台一页三段**（新 `ui/settings/DirectorConsoleScreen`+ViewModel＋AIChatApp 一行接线＋SettingsScreen 入口）：

| 摩根斯 | 触发源开关+概率（meeting_end/director_rules 两行）·用户船团兜底键 | writeTrigger/writeUserFleetKeyOverride |
| B9 调参+观测 | 四数（概率/日上限/对冷却/代理时效）＋**立即扫描**按钮＋最近 dir-r: 事件列表 | writeDirectorTuning＋扫描触发 |

事件压级/知情名单（EventOverride）**不进首切片**——按 sourceRefUuid 手填的工程操作面太糙，合理形态=从事件浏览页点选（依赖段二的列表基建，量级+，见拍板②）。
B8 文游入口**不进首切片**——cast 多选+会话选择+回合 UI 交互面大，单列切片二（见拍板③）。

## 三、拍板点（预置默认=首选项）

① **控制台入口口径**（冲突见勘察 6）：
　默认提案=**设置页普通入口，release 可达**（业主即唯一用户；面板文案标注"导演台"）。
　备选=隐藏入口（设置页连点版本号 5 次解锁·沿 Android 惯例）/DEBUG 双守卫（则 release 永不可达=违背拍板③，不建议）。
② **事件压级/知情名单形态**：
　默认提案=**进切片二**：待段二事件列表落地后按事件行点选配置（detailOverride 四态+allowList 勾选）。
　备选=首切片即做手填 uuid 工程形态（快但糙，验收期凑合可用）。
③ **B8 入口位**：
　默认提案=**聊天页内**（角色会话菜单"导演进场"——host 会话天然就是当前会话，省会话选择器）。
　备选=控制台内开演（选卡+选会话+选模式全在台内，路径长但集中）。
④ **立即扫描实现口径**：
　默认提案=**WorkManager expedite 入队**（同一 worker 代码路径·与周期扫纪律同构，不另开临时通道）。
　备选=临时直调 service（少一层队列但绕开排程纪律，验收行为可能与线上漂移）。
⑤ **范围确认——不做"新闻人工催发"**：延迟触达（6h/24h）是中继3 验收项，催发按钮会污染验收口径。首切片不提供任何新闻侧人工触发，仅 B9 扫描可手动（扫描≠发新闻，报道仍走 30% 概率）。
