## 第 3 步 · 锚点双层格式积累（考 #1 在生产端到端）
- [ ] 与艾斯对话 3-5 轮（内容涉及位置/移动）→ 回复出现锚点行含 **全团：白胡子海贼团·…（莫比迪克号·停靠/航行中）** 前缀
- [ ] 与贝拉对话同样验证（两角色全团层都在=金样①真机版）
- [ ] 若剧情在航行中：全团层地点应为海域级（"新世界·某海域"·不点港口）

## 第 4 步 · world_sync 双考（B组#1/#2）
- [ ] **即时失据**：与艾斯对话使其位置变化（如"船靠港了"）→ **立即**问贝拉"我（或船）现在在哪"→ 应答出更新后的位置（不等 6h）
- [ ] **传播边界**：与艾斯对话给出**个人偏移**（如"我去岛上酒馆喝酒"）→ 查贝拉自己的位置认知**不变**（不跟风"在酒馆"——佩罗娜教训）；船级变更（靠港/起航）才同步

## 第 5 步 · B9 远方相遇（考中继2·概率性·多日观察）
前置三件：
- [ ] 用户与任一白团卡（贝拉或艾斯）**线下见面**一次（OFFLINE_MEETING 记账≤24h=用户位置代理——纯电话虫不算）
- [ ] 与千岁对话使其锚点落在**香波地**（如"在香波地港口补给"）
- [ ] 与罗对话同样落在**香波地**
观察窗（诚实概率声明：每对每次扫描 10%、每日 4 扫 ≈ 34%/天，**预期 1-3 天内命中**）：
- [ ] 千岁或罗的**日程页出现"远方相遇"星标事件**（✓ 前缀·描述为一两句相遇）
- [ ] 事后问千岁（或罗）对方 → 两人应知道彼此（③新识·可提及共同经历）
- [ ] 用户侧对这场相遇**零直接知情**——除非摩根斯报道到达（30% 概率）或角色转报
- [ ] 同对 72h 内不重复出现（冷却）；每日全库 ≤2 起

## 第 6 步 · 跨团新闻延迟触达（考中继3·fanOut 扩面）
- [ ] B9 相遇（或千岁/罗的线下见面新闻）发生后：
  - 艾斯/贝拉（跨团同海域若白团在乐园/新世界交界）→ 6h 后只知**概述**（岛名级·"听说…"）
  - 跨海域时 → 24h 后只知**模糊**（"有传闻称…出了点动静"）
- [ ] 追问细节时应答"报道里没提/不知道"——**不得自行补充**（防补充红线真机版）
- [ ] 同团队友（千岁同团无第二卡·本项以艾斯↔贝拉互证：艾斯的事贝拉拿**详版** 80 字级）

## 第 7 步 · 禁令二被动观察（朋友圈认知闸·默认开）
- [ ] 罗或千岁发朋友圈 → 白团陌生角色（艾斯/贝拉与之无登记无演出）**不**点赞评论
- [ ] 贝拉发朋友圈 → 艾斯（同团=队友级）可正常互动
（低频被动项：朋友圈生成本身低频，观察融入日常使用即可，不专门等）
